# Community roadmap

Issues and pull requests are welcome for every item below. Contributions can be small: a translation correction or one controlled unlock observation helps.

- Confirm the remaining named skin and customization conditions in-game, especially shared Champion rewards and interactions with completed ghost challenges.
- Expand synthetic fixtures for older patch layouts and additional rejection cases.
- Investigate safe creation of missing time-attack entries; preserve the distinction between progression, record time and replay data.
- Decode additional Adventure hub/door progression beyond the first hub, retaining unknown bits.
- Improve catalogue browsing, accessibility, keyboard navigation and high-DPI layout.
- Review regional/title-version compatibility and document observed differences.
- Improve the separation of editor coordination and individual views as behavior grows.

Not currently provided: console decryption, server inventory editing, invented ghost replays, or a guarantee that every native mapping is verified in-game. See the README feature table before reporting an unsupported case.
