# App icon

`app-icon.png` is an original AI-generated mascot created with the built-in OpenAI
image generation tool for this project. It depicts a blue floppy disk wearing an
orange racing helmet with a checkered flag; no official game character or logo
was used. The repository license applies to this project asset where applicable.

`app.ico` contains seven transparent PNG frames, 16–256 pixels, used by both
executables and the GUI window. Rebuild the format conversion on Windows with
`pwsh ./scripts/build-icon.ps1`. This preserves the artwork and alpha channel.

## Generation prompt

Use case: logo-brand. Asset type: Windows executable application icon for a
community kart racing save editor. Create a cute, polished original icon: a
chunky blue floppy-disk mascot with two small friendly eyes, a bright orange
racing helmet and a tiny simple checkered flag tucked behind it. Friendly
arcade-game workshop feeling, clean bold silhouette, rounded shapes, limited
navy/cyan/orange/white palette matching a blue racing launcher UI, subtle 3D
highlights, readable at 32 pixels. Single centered isolated mark, square
composition, generous transparent margins, genuinely transparent background.
No text, no lettering, no official game characters, no existing logos, no
watermark. This should look like one cohesive app icon, not a scene or a mockup.
