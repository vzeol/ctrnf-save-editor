# Security

The latest 1.x release is the supported release line. Older releases and previews may not receive fixes.

For a vulnerability that could expose private data or cause unintended file writes, use [GitHub private vulnerability reporting](https://github.com/vzeol/ctrnf-save-editor/security/advisories/new). Include a synthetic reproducer where possible. Do not attach personal profiles or game binaries. If reporting is unavailable, open an issue requesting a private reporting channel without disclosing exploit details.

For ordinary format errors, missing unlocks or UI bugs, use the issue templates. The editor handles untrusted binary data; keep independent backups and use supported decrypted files. See CONTRIBUTING.md for evidence and data-sharing guidelines.
